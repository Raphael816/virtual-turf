# 16. 馬券システム（第11段階）

JRA の発売方式に合わせて、券種を8つにし、払戻の計算・同着・返還・特払いの扱いを整理した。
実装は `src/core/bettypes.ts`（券種・的中・返還の決まり）、`src/core/pool.ts`（オッズと払戻）、`src/core/probability.ts`（組合せの確率）、
`src/core/raceflow.ts`（締切・確定の流れ、同着の判定、出走取消）、`src/core/state.ts`（券の精算）。
**公式**は JRA の決まりそのまま、**推定**はゲームのための設定値。デモコインだけを使い、金銭的な価値はない（docs/03）。

JRA「馬券のルール」 https://www.jra.go.jp/kouza/baken/ （発売・払戻・返還・払戻金の計算方法【競馬法施行規則】・勝馬投票法ごとの払戻率）。

## 2. 券種・払戻率・発売する頭数（公式）

| 券種 | 当て方 | 払戻率 | 発売する出走頭数 |
|---|---|---|---|
| 単勝 | 1着の馬 | 80% | 2頭以上 |
| 複勝 | 3着以内の馬（5〜7頭のときは2着以内） | 80% | 5頭以上 |
| 枠連 | 1着・2着の枠番の組合せ | 77.5% | 9頭以上 |
| 馬連 | 1着・2着の馬番の組合せ | 77.5% | 3頭以上 |
| ワイド | 3着以内の2頭の組合せ（的中は3通り） | 77.5% | 4頭以上 |
| 馬単 | 1着・2着の馬番を着順どおり | 75% | 3頭以上 |
| 3連複 | 1着・2着・3着の馬番の組合せ | 75% | 4頭以上 |
| 3連単 | 1着・2着・3着の馬番を着順どおり | 72.5% | 4頭以上 |

- 発売する券種・複勝の対象・枠番は**発売開始時の頭数**で決まり、あとで出走取消があっても変わらない（公式）
- 枠番（公式）：8頭以下は1枠1頭、9〜16頭は外の枠から2頭ずつ、17頭は8枠が3頭、18頭は7・8枠が3頭ずつ。
  以前は17・18頭のとき9枠ができる誤りがあり、この段階で直した
- 枠連は、2頭以上いる枠だけ「同じ枠どうし」（ゾロ目）を買える
- WIN5 は扱わない

## 3. オッズと払戻の計算（公式の算式）

オッズは固定ではなく、投票の状況（プール）で決まる。

```
的中した組合せごとの払戻対象総額 = (W + D/P) × R
  W：その組合せへの投票額   D：的中しなかった組合せへの投票額の合計（返還分は含めない）
  P：的中した組合せの数     R：払戻率
オッズ = 払戻対象総額 ÷ W   （100コインあたり10コイン未満は切り捨て＝0.1倍単位、最低1.0倍）
```

- 的中が1つ（単勝・枠連・馬連・馬単・3連複・3連単のふつうの場合）なら「プール総額 × R ÷ W」と同じ
- 複勝（P＝3 または 2）・ワイド（P＝3）は、一緒に3着以内に入る馬で払戻が変わるので、確定まで幅（下限〜上限）で表示する
- 発売中のオッズは「的中が1つ」と想定した概算で、同着のときは違う率になる（公式の説明と同じ）
- 以前の複勝の式（利益を等分する形）は、公式の算式に置き換えた
- **簡略化**：JRAプラス10（元返しになるときの上乗せ）は扱わない。的中した組合せのうち投票のないものは P に数えない

### 3.1 市場プール（推定）

他の利用者の投票は「市場プール」で模擬する（デモ）。配分は 的中確率（下の4）に、次のずれを掛けたもの。

- 大穴が実際の確率より買われやすい傾向：確率の 0.92乗
- 市場の見立てのずれ：組合せごとに、対数の標準偏差 0.3（以前は 0.15）。**人気と実力は必ずしも一致しない**
- 発売中のゆらぎ：10秒ごとに変わり、締切に近いほど小さい
- どの組合せにも少しは票が入る（平均シェアの 5% を下限に上乗せ）
- 券種ごとの規模（デモコイン）：単勝 200万、複勝 250万、枠連 100万、馬連 450万、ワイド 250万、馬単 200万、3連複 600万、3連単 1,000万
  （3連単・3連複が大きく枠連が小さい、という JRA の売上の傾向に合わせた。割合は筆者の知識による目安で、公式の統計ではない）

利用者の投票も同じプールに入るので、自分の投票でもオッズが動く。

## 4. 組合せの確率（推定）

単勝・複勝の確率は、公開の乱数で数百回レースを計算して数える（結果決定用の seed は使わない）。
組合せの券種は数が多く（18頭の3連単で 4,896通り）、数百回では数えられないので、単勝の確率から作る。

```
1着 i・2着 j・3着 k の確率 = p_i × q_j/(1−q_i) × r_k/(1−r_i−r_j)
q は p の 0.88乗、r は p の 0.8乗を、合計が1になるようにしたもの
```

指数が1ならハービルの式。2着・3着は1着ほど実力どおりに決まらない、というよく知られた傾向を指数で表した（指数の値は推定）。
馬連・馬単・3連複・ワイド・枠連は、この確率を足し合わせて作る。

## 5. 同着（公式）

- 1着同着：いずれか1頭を1着、いずれか1頭を2着、いずれか1頭を3着とみなす
- 2着同着：いずれか1頭を2着、いずれか1頭を3着とみなす
- 3着同着：いずれか1頭を3着とみなす
- ワイドの3着どうしの組合せ、3連複・3連単の3着どうしを含む組合せは的中にならない

実装では「同着の馬の並べ方をすべて試し、どれかの並びで的中する組合せ」を的中とする。上の決まりと同じ結果になる（テストで確認）。
例：1着同着なら単勝は2頭とも的中、馬単は2通り、馬連は1通り。3着同着なら複勝は4頭、3連複は2通り。

**同着の判定（推定）**：ゴールの時間差が 0.0003秒（約 5mm）未満なら同着とする。JRA は写真判定で見分けられないときに同着とする。
166レースの集計で、同着は2回（うち4着以内は0回）だった。

## 6. 返還（公式）

発売開始後に出走取消・競走除外があったとき、次の券は全額を返還する。

- 単勝・複勝：その馬番
- 馬連・馬単・ワイド・3連複・3連単：その馬番を含むすべての組合せ
- 枠連：その馬の枠に他の馬がいなければ、その枠との組合せを返還。他の馬が1頭なら、同じ枠どうしの組合せだけ返還。2頭以上なら返還しない

返還分はプールから除いてから払戻を計算する。電話・インターネット投票と同じく、発表（締切のとき）にすぐ返還する。

**出走取消の起こり方（推定）**：締切のときに決まる。1頭あたり 0.3%、1レースに1頭まで、6頭以上のレースだけ。
結果決定用の seed から決めるので、締切の前には分からない。取消の馬を除いてレースを計算し、その馬の戦績には記録しない。
観戦しなかった開催日（画面を閉じていた間）では起こらない（投票がないため。簡略化）。

レースが行われなかったとき（計算の版が変わって開催を作り直すとき）は、以前からのとおり全額を返還する。

## 7. 特払い（公式）

その券種に的中者がいなかったときは、投票した全員に、払戻率 80% の券種（単勝・複勝）は 100 につき 80、70%台の券種は 70 を払い戻す。
市場プールがあるので、ふつうは起こらない（決まりとテストは用意してある）。

## 10. 残っている課題

- **1番人気の勝率が約4割**（JRA は3割強、という筆者の知識による目安より高い）。市場のずれを大きくしても変わらず、レース計算で強い馬が勝ちすぎることが原因。第15段階（検証）で扱う
- ボックス・流し・フォーメーションの買い方がない（1組ずつ買う）
- 3連複・3連単のオッズ一覧は人気上位10組だけ（全組合せの表はない）
- 降着・失格（審議）はない。WIN5、JRAプラス10 はない
- 出走取消は1レースに1頭まで。観戦しなかった開催日では起こらない
- 以前の開催の出走表（公開前に作られたもの）で17・18頭のレースは、枠の色が古いまま表示される（次の開催から正しくなる）
