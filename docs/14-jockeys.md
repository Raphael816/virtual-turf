# 14. 騎手システム（第9段階）

実装は `src/core/jockey.ts`（技術・適性・相性・減量・成績）、割り当ては `src/core/meeting.ts`、レースへの効き方は `src/core/sim.ts`、画面は `src/ui/pages/jockey.ts`。
登場する騎手30人はすべて架空。**公式**は JRA の制度そのまま、**推定**はゲームのための設定値。

## 1. 技術（8つ。0〜100）

騎手は「能力の補正値ひとつ」ではなく、技術ごとにレースの別の場面に効く（基準 72 との差で効く。効果の大きさは推定）。

| 技術 | 効く場面 |
|---|---|
| スタート技術 | ゲートの反応の遅れ（差 0.1 につき 0.015秒）、出のばらつき、出遅れの確率 |
| 位置取り | 狙った位置を取れるか（位置取りのばらつき）、外にいるとき控えて前の馬の後ろへ入る判断 |
| ペース判断 | 道中（仕掛ける前）のスタミナの消耗（差 0.1 につき 0.7%） |
| 折り合い | 掛かる確率（差 0.1 につき 2割） |
| 仕掛けの判断 | 仕掛けの地点のばらつき |
| コーナリング | コーナーでの減速、外を回る距離損（差 0.1 につき 3%） |
| 追う技術 | 末脚の伸び（差 0.1 につき 0.07%）、叩き合いの強さ |
| 判断の安定性 | その日の騎乗の出来のばらつき |

経験（免許からの年数）が長いほど、ペース判断と判断の安定性が高い。

## 2. 適性と相性（その日の技術の上下。推定）

得意な競馬場（2場）+4、得意な距離 +3（離れた区分 −2）、芝・ダート 得意 +2・不得意 −3、馬との決まった相性 ±4（組み合わせごとに一定）、
乗り慣れ 1回につき +1（3回まで）、脚質が合う +2・合わない −2。合計が ±3 以上のとき、出馬表に「好相性」「相性△」と出す。

## 3. 減量（公式）

JRA「減量制度」（https://www.jra.go.jp/kouza/yougo/w574.html ）のとおり、特別競走・ハンデキャップ競走以外で負担重量を減らす。

| | 勝利数 | 減量 | 印 |
|---|---|---|---|
| 男性の見習騎手 | 30勝以下／31〜50勝／51〜100勝 | 3kg／2kg／1kg | ▲／△／☆ |
| 女性の見習騎手 | 50勝以下／51〜100勝 | 4kg／3kg | ★／◆ |
| 女性騎手（見習でない） | — | 2kg | ◇ |

見習騎手を「免許を受けてから5年未満」とするのは筆者の知識によるもので、公式ページでは確認していない。障害競走の減量はゲームにないので扱わない。
ゲーム開始時点の通算勝利数は、年数と技術から見積もった値（推定）。

## 4. 騎手の割り当て（推定）

有力な馬（能力の高い馬）から順に騎手を決める。上手な騎手ほど選ばれやすく、前走で乗った騎手は続けて乗りやすい（4倍）。
減量のある騎手は一般競走で少し選ばれやすい（1kg につき 1.25倍）。1レースに同じ騎手は1頭だけ。
その日の技術と減量は出走表に写して保存するので、過去のレースは同じ結果で検証できる。

## 5. 検証

- 同じ能力の馬に、最上位（技術90）と最下位（55）の騎手が乗ると、上位が約65%先着し、差は平均 約2.3馬身
- 能力の高い馬＋下手な騎手は、能力の低い馬＋上手な騎手に6割以上先着する（騎手は馬の能力を覆さない）
- 技術ごとに別の場面に効く：折り合い→掛かりの回数、スタート→出遅れの回数、コーナリング→外を回る距離損
- 1年分（約390レース）：リーディング上位の勝率 9〜14%、下位は 0〜5%。出走のうち減量のある騎乗は約1割。
  勝ち馬の脚質（逃げ20・先行43・差し27・追込10%）と着差（中央値 1.3馬身）は第8段階とほぼ同じ

## 6. 残っている課題

- 騎手の引退・新人のデビュー（年ごとの入れ替わり）はまだない。年数は年明けに進み、見習の期間は終わる
- 上位の騎手に騎乗が集まりすぎる（上位は年に約350戦）。1日の騎乗数の上限や、複数の競馬場への分散はない
- すぐコーナーのコースで1番枠が有利すぎる点（第8段階の課題）は、位置取りの技術を入れたが、内ラチ沿いの取り合い・包まれる不利のしくみはまだない
- 騎手の指示（プレイヤーが乗り方を選ぶ）は馬主の機能（第13段階）で扱う
