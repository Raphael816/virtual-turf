# 04. 3D映像の品質改善（中継品質への作り直し）

## 1. 以前の映像が安っぽく見えた原因

| 項目 | 以前の実装 | 問題 |
|---|---|---|
| 馬のモデル | 球を引き伸ばした胴、円柱の脚、箱の頭（約20個の基本図形） | 筋肉・関節・たてがみがなく、おもちゃのような形。単色でプラスチックのような表面 |
| 走行アニメーション | 脚の角度を sin 波で振るだけ | 蹄が地面に着かず、滑ったり浮いたりして見える。全馬が同じ動き |
| ライティング | 太陽光と半球光だけ。影は狭い範囲 | 環境光（周囲からの反射光）がなく、のっぺりした陰影 |
| カメラ | 画角26〜48°で馬の近くに置く。タイマーで切り替え | 広角で近づくので、ミニチュアのような遠近感。ピントのぼけや動きのぶれがない |
| コース・背景 | 同じ模様の繰り返し、箱の観客、円錐の木と山 | 単調で平面的 |
| 画面表示 | 大きな馬番チップを映像の下部に表示 | ゲームの画面のように見える |

## 2. 改善内容（効果の大きい順）

### 2.1 馬のモデルと走行（`render/three/horseModel.ts`, `gait.ts`, `loft.ts`）
- **形**：断面をつないで胴・首・頭を生成する。断面の形を少しずつ変えて、肩・トモの筋肉、胸、腹のくびれを表す。サラブレッドの体高約1.63mを基準にした。
- **脚**：1本ずつ継ぎ目のないスキンメッシュにし、上腕／下腿・管骨・繋の3本の骨で変形させる。膝・飛節・球節は滑らかに曲がる。蹄は底が平らで、前壁が傾いた形にした。
- **歩様**：回転襲歩の着地順と、速度に応じた着地時間・ピッチ・歩幅を計算する。着地中は蹄を地面に固定し、膝と飛節の角度は2関節IKで逆算するため、**蹄は滑らない**（テストで確認）。着地中は球節が沈み、遊脚中は繋を折りたたむ。
- **体の動き**：完歩の位相に合わせて、体の上下動・前後の揺れ・首のうなずきを付ける。コーナーでは内側へ傾く。尾は4本の骨をばねで遅らせて揺らし、たてがみはシェーダーでなびかせる。
- **個体差**：歩幅のピッチ（±4%）、着地時間、手前（左右）、脚の上げ方、頭の高さ、体格（±3.5%）を、馬ごとに変える。
- **毛色**：頂点色で自然なムラを付ける。鹿毛は脚先・たてがみ・尾を黒く、芦毛は連銭模様にし、靴下・流星などの白斑は馬ごとに変える。毛並みの法線マップと、高画質では光沢（シーン）を加える。
- **騎手・馬具**：騎手は短いあぶみで立った前傾姿勢にし、馬の上下動を膝で吸収する動きにした。最後の直線では追う。勝負服は架空の配色と柄、帽色は枠の色。馬体に沿ったゼッケン（両側に馬番）、鞍、腹帯、頭絡、手綱を付けた。
- **重なり防止**：馬同士が重なって見える場合は、映像の上だけ横にわずかに離す（シミュレーションの結果は変えない）。

### 2.2 ライティング（`environment.ts`）
- 物理ベースの空（Preetham モデル）と雲の層を使い、時間帯（昼・薄暮・ナイター）と天候で太陽の高さ・空の色・雲の量を変える。
- 空から環境光（IBL）を生成して、自然な陰影と映り込みにする。
- 影は高解像度にし、計算する範囲をカメラが映している場所に限定する。影を計算しない軽量設定でも、馬の足元に接地影を付ける。
- 距離による霞み（指数フォグ）と、映画的なトーンマッピング（AgX）を使う。

### 2.3 カメラワーク（`camera.ts`, `post.ts`）
- 望遠レンズで遠くから撮る、競馬中継の構成にした。
  - 全景・先頭集団：スタンド屋上の主カメラ
  - 並走：外ラチ沿いを走るカメラカー
  - 正面：ゴールの先から直線を見る
  - ゴール板の横、注目馬の後方
- 撮りたい馬が画面に収まるように画角を自動で計算する。注視点は馬の速度で先読みして追うので、時速60km近い馬からも遅れない。
- 自動では、レースの局面（発走・コーナー・直線・最後の直線・ゴール）に応じてカットで切り替える。各ショットには最低限の長さを設ける。「動きを減らす」設定では切替を最小限にする。
- 高画質では被写界深度とモーションブラーを加える。モーションブラーはカメラの動きから計算し、馬のマスクを使って、追っている馬にはぶれをかけない（背景だけが流れる流し撮り）。ブルームのような派手な発光は使わない。

### 2.4 コースと背景（`environment.ts`, `effects.ts`, `textures.ts`）
- 芝・ダート・芝生は、色と法線のテクスチャに加えて、世界座標のノイズで場所ごとの色ムラを付け、繰り返し模様を目立たなくした。
- 芝には内ラチ沿いの傷みと刈り込みの縞を、ダートにはハロー掛けの筋を入れた。道悪では色が濃くなり、ダートは水気で光る。
- 蹄の着地位置（歩様から算出）に合わせて、砂煙（光で照らされる柔らかいスプライト）、土くれ・芝の塊、蹄跡を出す。
- スタンドは2層の座席、片持ちの屋根と梁、ガラス張りの建物で構成した。観客は人型で、ゴール前では盛り上がる動きをする。木立・生垣・2層の稜線・街並みは、霧で遠くほど霞む。
- 内馬場は、スタンドから向こう正面を見る視線を遮らないように、木や大型ビジョンを配置した。

### 2.5 画面表示
- 情報は上端の細い帯にまとめた（レース名・残り距離・タイム）。
- 残り600mからは、上位3頭の馬名をロワーサード（画面左下の小さな帯）で表示する。
- 順位帯は下端に小さく表示する。映像の中央は空けておく。

## 3. 画質設定

| 項目 | 低（軽量） | 中 | 高 |
|---|---|---|---|
| ピクセル比の上限 | 1.0 | 1.5 | 2.0 |
| 影 | なし（接地影のみ） | 2048 | 4096 |
| 馬モデルの細かさ | 簡略 | 標準 | 詳細＋毛並みの光沢 |
| 観客 | 1,800人 | 6,000人 | 14,000人 |
| 被写界深度・モーションブラー | なし | なし | あり |

- **自動**：タッチ端末は「低」、それ以外は「中」から開始する。3秒平均が30fpsを下回ると、ポストプロセス → ピクセル比 → 影 → 粒子の順に段階的に下げる。
- 映像の再生は時刻に同期しているので、フレームレートが下がってもレースは最後まで同じ時間で進む。
- WebGL2 が使えない端末では、2D上空図で表示する。

## 4. 素材と権利

| 素材 | 出典 | ライセンス・扱い |
|---|---|---|
| 馬・騎手・馬具の3Dモデル | コードで生成（`horseModel.ts`） | 自作。外部モデルは不使用 |
| 芝・ダート・芝生・座席・雲などのテクスチャ | Canvas で生成（`textures.ts`） | 自作。外部画像は不使用 |
| 空のシェーダー（Preetham） | three.js 付属の `Sky.js` | MIT ライセンス（three.js） |
| ポストプロセスの基盤（`Pass`, `OutputPass`） | three.js 付属 | MIT ライセンス |
| 映像・音声 | なし | — |
| フォント | 端末のシステムフォント | 配布しない |
| 競馬場・競走馬・騎手 | すべて架空 | 実在の競馬場の形状・名称・映像、実在の馬・人物は使っていない |
| 勝負服・帽色 | 勝負服は架空の配色。帽色は枠番の一般的な慣習色 | 実在の馬主の勝負服は使っていない |

外部の3Dモデルやモーションキャプチャを将来導入する場合は、商用利用の可否、クレジット表記の要否、「エディトリアル用途のみ」などの制限、改変の可否を確認すること。実在の競馬場・競走馬・騎手を扱う場合は、名称・外観・肖像・映像の利用許諾が必要かどうかを、法務とともに確認すること。

## 5. 今後の課題
- 実機での性能計測とチューニング。開発中の確認はソフトウェア描画（SwiftShader）で行ったため、実際のフレームレートは未計測。
- 騎手の造形と動きの詳細化（鞭の動作、腕のしなり）。
- 観客の距離別の詳細度（LOD）、雨天時の水たまりの映り込み。
- 実写により近づけるための、モーションキャプチャ相当の動きのデータ。権利処理が済んだものに限る。
