# 06. 本格的な競馬シミュレーションへの改善計画

## 1. 現状分析（変更前の調査結果）

| 領域 | 変更前の状態 | 現実の競馬との主な違い |
|---|---|---|
| 競走馬 | 架空の36頭。能力6種・脚質・最適距離1点・芝/ダ/道悪の適性がコードに固定 | 年齢・能力が変わらない。成長・衰え・疲労・故障・引退・戦績がない |
| 番組 | 毎回同じ8レース（名前・芝ダ・距離・時間帯が固定） | クラス・収得賞金・出走条件・負担重量がない。同じ日の連闘がありうる |
| 調子 | レースごとの乱数（最高速度に ±） | 調教・レース間隔・前走と無関係 |
| 騎手 | 名前を無作為に割り当てるだけ | 結果に影響しない |
| 適性 | 最適距離1点からの差で一律に減点 | 適性の幅・個体差、回り・坂・小回り・直線の長さへの適性がない |
| 馬場 | 天気からレースごとに無作為に決定 | 開催を通した含水・芝の傷み・内外差がない |
| コース | 中山を参考にした1場（現在は左右反転して左回り） | 10場の違い（東京と中山など）を表現できない |
| 馬券 | 単勝・複勝・馬連・馬単。控除率は券種ごとに20〜25%（デモ設定） | 枠連・ワイド・3連複・3連単、特払い・同着がない。JRAの控除率と一部異なる |
| 時間 | 現実の時刻で発走（約4分間隔）。開催日は手動で作り直し | ゲーム内の暦がない |
| 保存 | 残高・購入履歴・現在の開催だけ。形式が変わると読み込まない | 競馬界の状態を保存できない |

すでにあるもの（重複して作らない）：0.1秒刻みのレース計算（スタートの遅れ・出遅れ、脚質ごとの位置取り、逃げ馬の競り合い、掛かり、スパート、風よけ、進路の詰まり、外を回る距離損、坂）、
計算結果をそのまま再生する3D/2D映像、実況と勝因の解説、パリミュチュエル方式のオッズ、結果を決める乱数のコミット・リビールと監査ログ。

## 2. 方針（利用者の選択）
- プレイヤーは**馬主＋馬券**の両方。自分の馬以外の競馬界も自動で動き続ける
- 競馬場は**実名**（所在地としての名前と公式のコースデータ）。レース名は架空（実在のレース名・ロゴは使わない）
- 回り方向は各競馬場の実際の向き
- ゲーム内の時間は**現実の時刻で進む**（1開催日 ＝ ゲーム内の1週）

## 4. 段階Aの仕様（`src/core/world.ts`）
- **暦**：年・週（1年52週）。開催日を1つ開くごとに1週進む。馬齢は1月（第1週）に一斉に加算（JRAと同じ数え方）。
- **競馬界**：既存の36頭（各世代の上位馬という位置づけ）に、手続き的に生成した架空の馬324頭を加えた360頭。生成した馬の能力はやや低めの分布（推定値）。
- **出走**：前走から3週以上空いた現役馬から選ぶ（同じ開催日に2度は走らない）。疲労のモデル（段階D）までの簡略化。
- **出走表**：出走時点の能力を写して保存し、レースの計算・検証はその値で行う（能力が後で変わっても過去のレースを同じ結果で再計算できる）。
- **戦績**：確定したレースを各馬の直近10走に記録（日付・レース・コース・馬場・頭数・馬番・着順・タイム・着差・上がり3F・通過順・騎手・確定オッズ・人気）。
- **進行**：開催日の全レースが確定して1分経つと翌週の開催日が始まる。画面を閉じていた間は、経過時間に応じた開催日（最大12）の結果だけを計算して進める（投票はないのでオッズ・人気なし）。
- **保存**：形式 v2。v1 の保存データは残高・台帳・購入履歴・監査ログを引き継いで移行する。
