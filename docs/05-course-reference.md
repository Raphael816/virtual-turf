# 05. コース形状の出典と推定箇所（中山競馬場を参考にした非公式の再現）

このプロジェクトのコースは、**中山競馬場の公開データを参考にして独自に作った3Dモデル**です。JRA（日本中央競馬会）とは関係ありません。JRAの図面・写真・映像・ロゴは使っていません。

| JRA「場内マップ」 | https://www.jra.go.jp/facilities/race/nakayama/rcmap/ | 施設の種類の確認のみ（ターフビジョン・パドックなどがあること） | 同上。地図の画像は使っていない |

## 3. 推定で補った箇所（実際の形状と異なる可能性があります）

| 項目 | このモデルでの扱い |
|---|---|
| コースの平面形 | 直線400m＋半円の楕円で近似。実際のコーナーの半径・形は未確認 |
| 外回りの形 | 2コーナーから接線方向に外へ分かれ、外側の向正面（半径150mのコーナー）を通って3コーナーで合流する形を、周長1,839.7mになるよう計算した。**実際の形は未確認** |
| 坂以外の起伏 | 「1〜2コーナーで上り、2コーナー付近が最も高く、向正面から4コーナーにかけて下る」という一般的な解説の傾向から推定。区間ごとの正確な標高は未確認 |
| ダートの起伏 | 芝と同じ傾向で、高低差だけ4.5mに合わせた |
| 発走地点 | 周回上の距離から計算（実際のポケット（引き込み線）は再現していない） |
| スタンド・付属棟 | 一般的な2層スタンドとして作成。実際の規模・形・外観とは異なる |
| 内馬場の障害コース | 周回と襷（斜めの走路）、生垣・竹柵を置いた。実際の周長1,456.4mより短く（約1,250m）、形と障害の位置は推定 |
| ターフビジョン | 内馬場の4コーナー寄りに配置（実際の位置は未確認） |
| 周辺の街並み | 住宅地と中層の建物を置いた一般的な表現 |

## 4. 名称・ロゴの扱い

- 画面上の競馬場名は架空の「翠ヶ原競馬場」のまま。「中山競馬場」の名称は、画面の競馬場名としては使っていない（商標や公式との誤認の恐れがあり、利用許可を確認していないため）。
- ドキュメントと「遊び方」では、コース形状の参考として「中山競馬場の公開データを参考にした非公式の再現」と記載している。
- 名称を使う場合は、事前に権利者への確認が必要。

## 5. シミュレーションへの反映

- コーナーで外を回るロスは、コースの曲率から計算する（どんな形のコースでも同じ式）。
- 上り坂では減速し、スタミナの消耗が増える。パワーのある馬ほど影響が小さい。下り坂ではわずかに加速する。
- これらの変更でレースの計算方法が変わったため、エンジンのバージョンを `sim-2.0.0` に上げた。それ以前の開催は、起動時に未確定の投票を返還したうえで作り直す。
