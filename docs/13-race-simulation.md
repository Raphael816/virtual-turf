# 13. 本格的なレースシミュレーション（第8段階）

実装は `src/core/sim.ts`（0.1秒刻みの計算）と `src/core/ability.ts`（能力・適性の効き方）。数値はすべて**推定**（多数のレースの自動シミュレーションで、
JRA の一般的な傾向に合うよう決めた。傾向は筆者の知識による目安で、公式の統計ではない）。

## 1. 変更前の問題（調査結果）

- **ラップの形が逆**：どの距離も前半が遅く後半が速かった（芝1200m 前半3F 35.3秒・後半3F 32.7秒。実際は前半の方が速いことが多い）。
  そのため、道中で脚を溜めた差し・追込が届きやすく、**勝ち馬の脚質が 逃げ 9%・先行 29%・差し 36%・追込 26%** と後方に偏っていた
- **予想どおりに決まりすぎる**：1番手（何度も走らせて最も勝つ馬）の勝率 57%、3着以内 89%、10番手以下の勝ち 0.9%
- **ペースの判定がずれていた**：先頭の馬の速さで判定していたため、弱い馬が先頭だとスロー扱いになり、「スローなのに後ろが勝つ」逆の傾向が出ていた
- **枠順の有利不利が極端**：同じ能力の10頭で、1番の勝率 22〜30%、10番 2%（外枠の馬が隊列の内に入れず、ずっと外を回っていた）

## 2. レースの段階

各馬の段階ごとの順位（`phasePos`）と、段階の区切り（`phaseMarks`）を結果に含める。

| 段階 | 区間 | 主な計算 |
|---|---|---|
| スタート | 〜200m | ゲートの上手さ（反応の遅れ 0.1〜0.6秒）、出遅れ（ゲート・気性）、加速。発走直後 250m はポケットの直線を近似して外を回る損を小さくする |
| 序盤 | 〜距離の25%（最低400m） | 位置取り争い（テンの速さ：隊列が巡航より速く流れる。逃げ馬が多いほど激しい）、二の脚（テンの速さで位置が前後する）、外枠から内へ入る横移動はスタミナを使う |
| 中盤 | 〜直線の入口の600m手前 | ペースへの対応（前の馬ほど先頭について行き、後ろの馬は自分のペース）、折り合い（掛かり）、風よけ、脚を溜める |
| 勝負どころ | 〜直線の入口 | 仕掛け（脚質・残りのスタミナ・騎手の判断のばらつき）、まくり（スローで脚が残っている差し・追込が早めに動く）、前の集団の応戦、コーナーで外を回る距離損、進路の詰まり |
| 最終直線 | 〜ゴール | 末脚（最高速度・瞬発力・残りのスタミナ）、持続力、坂、短距離の終いの失速（全馬共通）、叩き合い（勝負根性＝持続力と気性）、スタミナ切れの失速 |

出来事（`events`）に「まくり」「叩き合い」を加え、実況とレースの振り返りに出す。

## 3. 主な計算の変更

- **巡航速度**：距離ごとに 1,000m 100%・1,200m 99%・1,600m 97%・2,000m 95.5%・2,400m 94.5%・3,200m 93%（最高速度に対する割合）。短距離は道中から最高速度に近い
- **スタートの加速**：巡航速度の99%まで強い加速を続ける（以前は95%まで）
- **序盤の位置取り争い**：最初の距離の40%（最大700m）で、隊列が巡航より最大 6%×√(1200/距離) 速く流れる。逃げ馬 0頭で半分、1頭で 0.75倍、2頭で標準、3頭以上で 1.25倍
- **スタミナの消耗の基準**：上の区間ごとの速さで走った基準の馬が、距離ごとの割合（1,000m 90%〜2,000m 85%）を使うように決める
- **短距離の終いの失速**：最後の600mで、ゴールでの速度が 1,000m 8%・1,200m 9%・1,600m 4%・2,000m 0% 下がる（全馬共通。スタミナの能力とは別の疲れ）
- **スタミナ切れ**：残りが少なくなったときの速度の下限を 80% → 92%（ばてた馬が極端に遅くならない）
- **ペースへのついて行き方**：逃げ 1・先行 0.85・差し 0.55・追込 0.3（1 なら先頭と同じ速さで追走）
- **隊列の長さ**：1頭あたり 1.6m（道中の隊列の間隔。広げすぎると着差が大きくなり、前の馬が有利になる）
- **風よけ**：他馬の直後につけたときの消耗 0.94倍
- **抜け出した馬を流す**：残り300mで先頭が2番手に一定の差（レースごとに 0.5〜2.5馬身）をつけたら、騎手は追うのをやめて2番手の速さに合わせる（最高速度の95%まで。力の差が大きい馬は大差で勝つこともある）
- **控える**：序盤に外にいて内へ入れない、ハナを主張しない馬は、3% 速度を落として前の馬の後ろに入る（外枠の馬が外を回り続けない）
- **ハナ争いの消耗**：競り合っている間の消耗 1.3倍 → 3倍（逃げ馬が多いと共倒れになりやすい）
- **ゲートの出のばらつき**：0.06秒 → 0.15秒（出の速かった馬が先に内へ切れ込める。内枠だけが有利になりすぎない）
- **力の劣る馬**：最高速度が出走馬の平均より低い馬は、先頭に無理について行かない。消耗の基準の速さも平均の近くまでとして扱う（ついて行くだけで急にばてない）
- **適性の減点の頭打ち**：−0.25 m/s を超える分はなめらかに頭打ち（最大 約 −0.4 m/s）。当日の出来は ±3σ まで
- **掛かり**：掛かっている間の消耗 1.4倍 → 1.7倍
- **出走の選び方**（meeting.ts）：芝・ダートの合わない馬、距離の離れた馬は出走しにくくした（調教師は合う条件を選ぶ）
- **単騎逃げのペース**：基準ペースの 99% → 100%
- **能力の差の大きさ**：`spreadScale`（速度・スタミナの差をそろえて縮める倍率）を用意した。現在は 1（縮めない）
- **前の集団の応戦**：後ろの馬が仕掛けたら、前の35%にいる馬も脚が残っていれば早めに仕掛ける
- **スピードの効き方**：短距離ほど大きい（1,200m 1.2倍・2,000m 1.0倍・3,000m 0.85倍）
- **スタミナの効き方**：短距離ほど小さい（距離の1.8乗に比例）
- **瞬発力**：末脚の伸びに直接効く（25 につき 1.2%）
- **坂**：上り坂での失速の係数 1.8 → 2.4
- **内へ寄せる**：前の馬の後ろに入れるなら内へ寄せる（外枠の馬も隊列に収まる）
- **不確実性**：当日の出来の幅を 3.3倍、仕掛けの地点のばらつき 40m → 80m、位置取りのばらつき 1.5倍、末脚のばらつき 2倍。
  騎手の能力（第9段階）がまだないため、その分のばらつきも含めている
- **走破時計**：上の変更のあと、距離ごとの速さの倍率を較正し直した（良馬場の目安：芝1200m 68.5秒、1600m 94.6秒、2000m 120.6秒、2400m 145.3秒、ダート1200m 71.6秒、1800m 112.0秒）

## 4. ペースの判定

実際の競馬と同じく、**先頭の前半と後半のタイムの差**で判定する。後半 ÷（前半 − 発馬の加速 1秒）− 1 から、距離ごとの標準（1,200m +2.5%・1,600m −0.7%・2,400m −3.2%）
を引いた値が −1.35% 以下ならスロー、+1.35% 以上ならハイ（多数のレースのおよそ下位・上位 25%）。

## 6. 残っている課題

- **1着と最下位の差がまだ大きい**（中央値 30馬身。実際は 10〜20馬身）：最下位の馬は、勝ち馬よりスタミナが平均6低く、ゴールでスタミナが尽きている。
  同じ能力の馬だけなら 10〜16馬身に収まるので、出走馬の能力差（とくにスタミナ）が原因。ばてた馬の失速を小さくすると前に行った馬が強くなりすぎるため、第15段階の検証で扱う
- **前に行った馬がやや強い**（逃げ・先行で 63%。目安 55%）
- **阪神芝内1200m のような、すぐコーナーのコースの1番枠**（18%。12頭なら均等で 8%）：内ラチ沿いの取り合い・包まれる不利は騎手の判断（第9段階）で扱う
- ポケットの発走地点・スパイラルカーブは近似（第6段階）
