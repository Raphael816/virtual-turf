# 08. 競走馬の生涯：成長・疲労・調子・故障・引退（第3段階）

実装：`src/core/lifecycle.ts`（計算）、`src/core/world.ts`（毎週・毎年の進行とレース後の処理）。検証：`tests/lifecycle.test.ts`。
数値は特記のない限り**推定値**（ゲームとしての調整値）です。週単位の決まった乱数で進むので、同じ経過からは同じ競馬界になります。

## 1. 成長
- 馬ごとに**能力の上限**（ピーク時のスピード・スタミナ・瞬発力・持続力・パワー）を持ち、現在の能力 ＝ 上限 × 成長曲線。
- 成長曲線は成長型で変わる：早熟は生後約2.7年（3歳春）で完成、普通は約3.8年（4歳）、晩成は約4.8年（5歳）。ピークの終わりは早熟4.2年・普通5.3年・晩成6.4年。馬ごとに ±0.25年程度の個体差。
- 2歳春の能力は上限の約82〜90%。**成長力**が高いほど、若いうちと完成時の差（伸びしろ）が大きい。
- ピーク後の衰えは1年あたり スピード・瞬発力3.5%、持続力2.5%、パワー2%、スタミナ1.5%（年を追うごとに少し速く）。スピードが先に衰え、スタミナは残る。
- 能力は毎週の進行で更新され、出走表には出走時点の能力が写る。
- 既存の36頭は今の能力を現在の値とし、上限を逆算。生成した馬は、生成した能力を上限とする。

## 2. 疲労と調子
| 項目 | 内容 |
|---|---|
| 身体的疲労（0〜100） | レース後に (20＋距離/80)×（重・不良で1.15）×健康の補正 だけ増える（1600mで約40、2500mの重馬場で約55）。毎週 5＋健康/20 回復（1600mの疲労は約5週で抜ける） |
| 精神的疲労（0〜100） | レース後に8（掛かったら＋10、大敗で＋4）。毎週4回復。たまると掛かりやすい |
| 調子（−1〜1） | 馬ごとの周期（10〜16週）の波。疲労が30を超えると下がり、故障明けの初戦は上がりきらない。精神的疲労でも下がる |
| 出走の判断 | 故障中・疲労30以上の馬は出走しない（調教師が見送る）。前走から2週以上空ける。疲労が残っている馬ほど選ばれにくい |
| レースへの効き方 | 調子は最大 ±0.06 m/s（絶好調と絶不調の差でも約0.12 m/s＝1600mで約0.6秒）。疲労は最大 −0.08 m/s とスタミナ −8%。**疲れていても必ず負けるわけではない** |

## 3. 故障
- レース後に判定（実際の競馬でも、レース後の検査で判明することが多い）。確率 ＝ 0.8%×(1＋疲労/40)×(1.45−健康/100)×（7歳以上1.3）×（重・不良1.15）。
- 種類（割合・治療期間・復帰後の能力の上限の低下）：筋肉痛・捻挫（38%・3〜6週）、球節炎・ソエ（22%・5〜10週・0〜1%）、骨折（30%・16〜32週・0〜3%）、屈腱炎（10%・40〜60週・4〜10%）。屈腱炎は半数がそのまま引退。
- レース中の故障（競走中止）は、レースの段階ごとの計算（第8段階）で扱う。

## 4. 引退と新しい世代
- 年明けに判断：年齢（5歳5%、6歳12%、7歳25%、8歳45%、9歳75%、10歳で全頭）、牝馬は5歳以上で繁殖入り（＋15%）、直近に勝てていない（＋10%）、重度の故障（＋40%）。
- 毎年1月に2歳の新しい世代が加わり、現役が約700頭に戻る。2歳馬は6月（第22週）からデビュー。
- 引退馬は直近300頭まで記録を残す（成績は直近5走）。繁殖（第12段階）で使う。

## 5. 検証（8年分の自動シミュレーション）
| 指標 | 結果 | 目安 |
|---|---|---|
| 現役の頭数 | 約700頭で安定 | — |
| 1頭あたりの年間出走 | 約7走 | JRA の一般的な水準（年5〜7走程度） |
| 1レースの平均頭数 | 約11.8頭 | 番組の頭数の設定（9〜14頭） |
| 故障（軽度を含む） | 1走あたり約0.85% | 推定 |
| 引退理由 | 高齢・成績不振・繁殖入り・故障 | — |
| 成長 | 早熟は3〜4歳、普通は4〜5歳、晩成は5〜6歳でピーク | — |

保存容量は、競馬界（約840頭・直近10走）で約1.4MB。

## 6. 既知の課題
- まだクラス・出走条件がないため、2歳馬と古馬が同じレースに出ることがある（第5段階で番組を作る）。
- 調教による成長・調子の変化は第4段階。
