# 01. プロダクト企画

## 1. サービス概要と想定ユーザー

**Virtual Turf（仮称）** は、架空の競走馬・騎手・競馬場で行う競馬シミュレーションです。
レース前に馬の能力・枠順・天候・馬場状態・オッズを検討して **仮想コイン（デモコイン）** で投票し、
レース中は3Dのスポーツ中継風映像で展開を見守り、レース後に着順・勝因・収支を振り返れます。

- 結果は「能力 × 適性 × 展開 × 乱数」で決まり、レース後にその理由が解説されます（意外性はあるが、理由を説明できる結果）。
- デモコインは **購入も換金もできず、金銭的な価値はありません**。

### 想定ユーザー

| セグメント | ニーズ | 提供価値 |
|---|---|---|
| 競馬ファン（ライト〜コア） | 予想する楽しさ、展開を読む面白さ | 能力・展開が反映される、納得感のあるシミュレーション |
| 競馬未経験のゲーム好き | 3Dレースの迫力、手軽さ | 遊び方の案内、単勝から始められる導線 |
| データ・戦略好き | 能力値と結果の関係を分析したい | 能力値・通過順・上がりタイム・シード検証の公開 |
| 将来の事業パートナー／法務 | 公正性・安全性の確認 | 監査ログ、コミット・リビール方式、責任ある利用の機能 |

対象年齢：試作でも **18歳以上の自己申告** を前提とします（実際の年齢基準は提供地域の法令に合わせて見直します）。

## 2. MVPの範囲

### MVPに含める機能

- **レース**：1開催8レース（芝／ダート、1200〜2400m、天候・馬場状態・時間帯が異なる）
- **シミュレーション**：能力値（スピード・スタミナ・加速・ゲート・気性・パワー）、適性（距離・芝・ダート・道悪）、脚質、枠順、ペース、進路の詰まり、掛かり
- **公正性**：結果決定用シードをレース前にハッシュで公開し、レース後にシードを公開して誰でも再計算できる仕組み（コミット・リビール）、ハッシュチェーンによる監査ログ
- **観戦**：3D映像（カメラは自動・全景・先頭集団・特定の馬・ゴール前）、実況テキスト、残り距離、順位、進行バー、再生速度の切替
- **代替表示**：2Dの上空図と順位表（WebGLが使えない場合や、ユーザーが選んだ場合）
- **投票**：単勝・複勝・馬連・馬単（券種を後から追加しやすい構成）、購入前の確認画面（賭け金・選んだ馬・オッズ・想定払戻額）、締切
- **オッズ**：パリミュチュエル方式（デモ用の控除率を明示）、発売中は変動し、締切で確定
- **収支**：購入履歴、レース別の収支、残高の推移グラフ
- **責任ある利用**：年齢確認の自己申告、1レース／1日あたりの投票上限、1日の損失額の通知、利用時間のリマインダー、一時休止（24時間・7日）、自己排除
- **設定**：画質（自動・低・中・高）、2D表示、動きを減らす表示、データの初期化
- データは端末内（localStorage）に保存し、サーバーは使いません

### 後回しにする機能

| 機能 | 後回しにする理由 |
|---|---|
| 実際のお金での入金・出金・賭け | 法務確認と許認可が前提（[03](./03-legal-and-safety.md) を参照） |
| デモコインの購入（課金） | 資金決済法・景品表示法・ストアの規約などの検討が必要 |
| 会員登録・サーバー側でのレース実行 | MVPは端末内で完結（本番では結果をサーバー側で決定する。[02](./02-architecture.md) を参照） |
| 複数人の同時観戦・チャット | 運用体制（モデレーション）が必要 |
| 3連複・3連単・ワイド・枠連 | 券種の登録の仕組みで追加できるようにしてある |
| 馬の育成・血統・成長 | コアの体験が検証できてから |
| 音声実況・BGM | 権利処理と音響の制作が必要 |
| 多言語対応 | 日本語で検証したあと |

## 3. 画面一覧と主要フロー

### 画面一覧

| # | 画面 | パス | 主な要素 |
|---|---|---|---|
| S1 | トップ | `#/` | 次のレース、残高と本日の収支、遊び方への導線、デモである旨の明示 |
| S2 | 遊び方・仕組み | `#/guide` | 3ステップの説明、デモコイン、オッズと払戻の計算、公正性の仕組み |
| S3 | レース一覧 | `#/races` | 各レースのレース番号・距離・芝ダ・天候・馬場・状態（発売中／確定） |
| S4 | レース詳細・観戦 | `#/race/:id` | 3D／2D映像、出馬表、オッズ、投票パネル、実況、結果と解説 |
| S5 | 馬の詳細 | `#/horse/:id` | 能力のレーダーチャート、適性、脚質、近走成績、短評 |
| S6 | 購入内容の確認 | S4内のダイアログ | 券種・選んだ馬・賭け金・現在のオッズ（変動中の表示）・想定払戻・購入後の残高・上限の状況 |
| S7 | 結果・収支 | `#/history` | 残高の推移、レース別の収支、購入履歴 |
| S8 | アカウント設定 | `#/account` | ニックネーム、利用上限、休止・自己排除、画質、監査ログの検証、データの初期化 |
| — | 年齢確認 | 初回のみのダイアログ | 18歳以上かどうかの確認、デモであることの説明 |

### 主要なユーザーフロー

```
初回訪問 → 年齢確認・デモの説明 → トップ（10,000コイン付与）
   → 「遊び方」(任意) → レース一覧 → レース詳細
   → 出馬表・馬の詳細で検討 → 券種と馬を選び、金額を入力
   → 確認ダイアログ（オッズ・想定払戻・残高）→ 購入
   → 締切（オッズ確定・シードのハッシュは公開済み）→ 3D観戦（カメラ切替・実況）
   → 結果（着順・払戻・勝因の解説・シードの公開と検証）
   → 収支画面 → 次のレースへ
```

責任ある利用の割り込み：
- 上限を超える購入はブロックし、理由を表示する
- 利用時間が設定した分数を超えると、経過時間と本日の収支を表示する
- 休止中・自己排除中は投票できない（観戦はできる）

### レイアウト方針（スマートフォン優先）

- **スマートフォン**：映像（16:9）を上部に固定し、その下をタブ（出馬表／オッズ／投票／実況）で切り替える。購入ボタンは親指で届く下部に置く。
- **PC（1024px以上）**：左に映像と順位、右に投票パネルの2カラム。
- 落ち着いた濃紺と芝の緑を基調にしたスポーツ中継のトーンにし、ネオンや金色を多用したカジノ風の表現は使いません。
- 煽る表現（「必勝」「今がチャンス」など）は使わず、結果は「的中／不的中」と事実だけを表示します。
