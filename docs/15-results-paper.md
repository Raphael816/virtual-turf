# 15. レース結果と競馬新聞（第10段階）

レース後の情報を充実させ、出走馬の過去の成績と適性を競馬新聞（馬柱）の形で見られるようにした。
実装は `src/core/bodyweight.ts`（馬体重）、`src/core/postrace.ts`（レース後のコメント）、`src/core/paper.ts`（新聞の集計）、
画面は `src/ui/pages/race.ts`（「新聞」タブ・「結果」タブ）。**公式**は JRA の公開している表記・制度、**推定**はゲームのための設定値。

## 1. レース結果の表

依頼の項目をすべて1つの表に並べた（JRA の成績表と同じ並び）。

| 項目 | もとになる値 |
|---|---|
| 着順・枠番・馬番・馬名・性齢・騎手・負担重量 | 出走表と計算結果（減量の印つき） |
| 走破タイム・着差・上がり3ハロン | 計算結果（上がり最速は色付き） |
| 通過順位 | 各コーナーでの順位 |
| 単勝オッズ・人気 | 締切時点の確定プール |
| 馬体重・増減 | 下の2 |
| 馬場状態 | 天候、芝・ダートの馬場状態、含水率、クッション値、使用コース、開催日数 |
| レース展開 | ペース、前半・後半3F、ラップ、「レースの振り返り」（勝因と1番人気の敗因） |
| レース後のコメント | 下の3 |

## 2. 馬体重（推定）

JRA は出走馬の馬体重を **2kg 単位**で発表し、前走からの増減を併せて示す（**公式**の出馬表・成績表の表記）。初出走の馬は増減がない。

ゲームでは、馬体重を**馬の状態の表れ**として計算する。馬体重そのものはレースの計算に入れない。
馬体重を動かしている要素（疲労・仕上がり・休み明け・成長）が、すでに調子や能力を通してレースに効いているためで、
同じ要素を二重に効かせないための簡略化である。

| 要素 | 値（すべて推定） |
|---|---|
| 完成時の体重 | 牡・セン 488kg、牝 464kg を中心に、標準偏差 22kg の個体差。パワー 1 につき +0.4kg（70 が基準）。400〜560kg |
| 成長 | 2歳の夏は完成時の約 −5%。4歳で完成 |
| 仕上がり | 50 を普通として ±5kg（強めの調教で絞れる） |
| 疲労 | 最大 −8kg |
| 休み明け | 10週以上空くと増える（最大 +14kg） |
| 当日のばらつき | 標準偏差 2.5kg |

1年分の自動シミュレーション（約4,200走）の結果：

- 馬体重：最小 392kg、5% 428kg、中央値 470kg、95% 514kg、最大 544kg（JRA の出走馬は 470kg 前後が中心、という筆者の知識による目安に合わせた。公式の統計ではない）
- 増減：±4kg 以内が約77%、±10kg 以内が約98%、±20kg 以上は 0.2%
- 増減と成績：−10kg 以下の馬は 3着内 18%（±8kg 以内の馬は 25%）。大きく減っている馬は疲労が残っていることが多く、成績が下がる。
  +10kg 以上の馬は 3着内 26% で、差はない（休み明けの増加は、成長分を含むため）

## 3. レース後のコメント

騎手の談話の形の短い文章を、全馬に付ける（1〜3着を表示、4着以下は折りたたみ）。
文章は自動生成で、騎手・談話とも架空。**そのレースの計算の記録にあることだけ**を述べる。

- 不利・ロス：出遅れ、掛かり、ハナ争い、直線で前が詰まった、外を回らされた
- 展開：ペースと位置取りの相性、まくり、叩き合い
- 適性：距離（スタミナが切れた・短い）、道悪
- 状態：馬体重の大きな増減（±10kg 以上）、当日の調子
- 脚：上がり3F が最速

当てはまるものを2つまで並べ、何もなければ着順に応じた一般的な文にする。言い回しはレースと馬番から決まり、同じレースからは同じ文章になる。

## 4. 競馬新聞（「新聞」タブ）

出走馬ごとに、左に馬の情報、右に**過去5走**（左が前走）を並べる。

- 馬の情報：馬番・枠・馬名・性齢・毛色・脚質・厩舎、騎手と負担重量、馬体重（増減）、単勝オッズと人気、通算成績、
  調子・前走からの間隔・直近の調教、適性（芝・ダート・道悪・今回の距離）、条件別の成績（この競馬場／芝・ダート／距離 ±200m／道悪）
- 短評：前走との違いと状態を、事実だけ並べる（休み明け、昇級戦、芝・ダート替わり、距離延長・短縮、前走の着差、斤量の増減、乗り替わり、馬体重の大きな増減、調子、この競馬場での勝利）
- 過去1走の中身：日付・クラス／レース名／コース・馬場・ペース／着順・頭数・馬番・人気／騎手・斤量／走破時計（1着との差）／通過順・上がり3F／馬体重（増減）／相手の馬

予想の印（◎○▲など）や、投票を勧める表現は出さない（docs/03 の方針）。

条件別の成績は、端末に保存している直近10走の中での集計で、生涯の成績ではない（保存容量のための簡略化）。

## 5. 保存データ

- 戦績（1走の記録）に、馬体重 `bw`・増減 `bd`・ペース `pc`・相手の馬 `vs` を追加した。項目の追加だけで、保存データの版（schema 5）は変えていない
- 以前の記録にはこれらがないので、馬体重は「—」、増減なしで表示する。公開前に作られた開催の出走表にも馬体重はなく、次の開催から付く
- レースの計算は変えていない（計算の版 `sim-4.1.0` のまま）。未確定の馬券の返金は起きない

## 6. 検証

- テスト（`tests/paper.test.ts`）：馬体重が 2kg 単位で現実的な範囲、牝馬が牡馬より軽い、疲労で減り休み明けで増える、出走表と戦績に記録される、
  全馬に着順どおりのコメントが付き出遅れ・掛かりに触れる、コース表記の分解、条件別の成績、短評
- 全体：232件のテストが成功、型検査・ビルドが成功
- 画面：戦績を14週分進めた保存データで、出馬表の馬体重、新聞タブ（15頭・過去走36件）、結果表の14項目、コメント、馬のページの戦績をヘッドレスブラウザで確認。スマートフォン幅で横にはみ出さない

## 7. 残っている課題

- 馬体重はレースの計算に効かない（状態の表れとして見せるだけ）。「太め残り」を独立した要素にするなら、仕上がりの計算と合わせて見直す
- 新聞の過去走は保存している10走まで。生涯の条件別成績（コース別・距離別）は持っていない
- 過去走に「そのレースで上がり何位だったか」「不利があったか」の記録はない
- 馬体重の発表時刻（発走前）やパドックの気配は扱っていない（パドックは第14段階）
- 結果表は項目が多く、幅の狭い画面では横にスクロールする
