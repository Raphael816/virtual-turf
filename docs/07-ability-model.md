# 07. 競走馬の能力・適性と、レースへの効き方（第2段階）

実装：`src/core/ability.ts`（能力・適性 → レースの計算に使う値）、`src/core/sim.ts`（レースの計算）。
検証：`tests/ability.test.ts`（能力・適性・脚質と展開）、`tests/sim.test.ts`。

数値の尺度（0〜100、平均的なオープン馬で75前後）はゲーム内の目安です。係数は**推定値**で、実際の競馬の傾向
（短距離ほど速度、長距離ほどスタミナ、重馬場でパワー、坂でパワー、ハイペースで差し・追込）と矛盾しない向きと大きさにし、
数百〜数千レースの自動シミュレーションで確かめています。速度の補正 0.1m/s は、1600mで約0.5秒（約3馬身）の差です。

## 1. 能力

| 能力 | レースでの効き方（計算） |
|---|---|
| スピード | 最高速度 ＋(値−75)×0.018 m/s |
| スタミナ | 消耗のしにくさ。倍率 1.125＋(値−75)/200×(距離/1600)。**長距離ほど差が大きく、短距離では小さい** |
| 瞬発力 | スタートの加速・巡航中の加速、直線の短いコースでの末脚の上乗せ |
| 持続力 | スパート中の消耗の倍率 1＋(75−値)/250、失速しはじめるスタミナ残量 0.3＋(75−値)/500 |
| パワー | ダートの速度、重い芝の速度、上り坂での失速の受けやすさ |
| 気性 | 掛かる確率 ((100−値)/100)^1.5×0.35、出遅れの確率 |
| 操縦性 | 掛かっている時間の倍率、位置取りのぶれ（騎手の指示どおりの位置に収まるか） |
| ゲート | スタートの遅れ、出遅れの確率、テンの速さ |
| 健康 | 当日の体調のばらつき（小さいほど安定）。故障しにくさは第3段階で反映 |
| 成長力・成長型 | 早熟・普通・晩成。成長の計算は第3段階で反映 |

## 2. 適性

| 適性 | 効き方 |
|---|---|
| 芝・ダート | A(85)で＋0.1、B(65)で0、C(45)で−0.2、D(25)で−0.4 m/s |
| 距離 | 中心距離・短い側の幅・長い側の幅。外れた量を幅で割った z で評価し、幅を超えると落ち方が急になる。長い側はスタミナの倍率が下がり、短い側は速度が落ちる。発揮の割合は exp(−0.29z²)（幅だけ離れて約0.75） |
| 馬場（道悪） | 重・不良で、A(85)は＋0.1、D(25)は−0.25 m/s（稍重はその2割）。60が普通 |
| 右回り・左回り | コースの回りの適性 (値−60)/40×0.08 m/s |
| 坂 | 上り坂での失速の受けやすさ (1.5−パワー/100)×(1.25−坂/200) |
| 小回り | コーナー半径190m未満で、コーナーの速度を最大2%（小回り適性で増減） |
| 長い直線 | 直線が長いほど、長い直線適性の高い馬の末脚が伸び、直線が短いほど瞬発力の高い馬に有利 |
| 暑さ・寒さ | 7〜8月（暑さ）・1〜2月（寒さ）に最大±0.05 m/s |

既存の36頭と、競馬界で生成した馬には、既存の能力と相関させた個体差を持たせています（例：持続力はスタミナと瞬発力の中間、操縦性は気性、坂はパワーと相関）。
追加の値がない古い保存データの馬は、既存の能力から決まった式で求めます。

## 3. 脚質と展開

- 脚質は**目安**で、実際の位置取りはメンバーで変わる：テンの速さ（ゲート・瞬発力・スピード・気性）がメンバーの中で速い馬ほど前に、遅い馬ほど後ろになる。逃げ馬がいないときはテンの速い先行馬が押し出されて先頭に立ち、ペースが落ちる。
- 追走する馬は先頭のペースに合わせる（逃げ馬のペースが隊列のペースになる）。
- 逃げ馬どうしが競り合うとペースが上がり、競り合っている間は消耗が大きい（×1.3）。
- 後方で追走する馬ほど消耗が少ない（脚を溜める。最大25%、距離が長いほど小さく）。溜めたスタミナは末脚に反映される。
- 並びかけられた先頭の馬は、予定の仕掛け地点の手前でも応戦して仕掛ける。
- 結果の内訳に「実際の位置取り」（1コーナーの位置）を表示する。

### 修正前の問題と、修正後の分布（能力が同じ12頭・芝、各数百レース）

| 条件 | 修正前（逃げ/先行/差し/追込） | 修正後 |
|---|---|---|
| 1600m・逃げ1頭 | 15% / 79% / 6% / 1% | 19% / 44% / 16% / 21% |
| 1600m・逃げ4頭 | 72% / 18% / 10% / 1% | 3% / 27% / 23% / 47% |
| 2400m・逃げ1頭 | — | 7% / 37% / 26% / 30% |

修正前は、どの馬も最後の600mを同じ時計で走り、コーナーでの位置がそのまま着順になっていた（逃げ馬が4頭で競り合っても逃げ馬が7割勝つ）。
修正後は、溜めた馬の上がりが速く（逃げ1頭のマイルで 逃げ34.2秒 → 追込34.0秒）、ハナ争いをした逃げ馬は上がりが遅くなる（35.3秒）。
調整値は `sim.ts` の `TUNE` にまとめている。レースの段階ごとの計算（第8段階）で、騎手の判断・進路・枠順とあわせて見直す。

## 4. 既知の課題（後の段階で扱う）
- 走破タイムは、芝1600m 1分35秒台・芝2000m 2分00秒台と実際の中山の水準に近いが、芝1200m（71秒台）は遅く、ダート1800m（1分50秒台）は速い。コースごとの調整は第6段階で行う。
- 脚質の分布は能力が同じ馬で確かめたもので、実際の勝ち馬の脚質の統計との照合は、コースと番組（第5・6段階）を入れてから行う。
