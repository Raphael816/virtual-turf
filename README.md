# Virtual Turf（仮称）

架空の競走馬・騎手・競馬場で遊ぶ **競馬シミュレーション（デモ）** です。
レース前に馬とオッズを検討して **デモコイン** で投票し、3D中継風の映像で観戦し、結果と収支を振り返ります。

> ⚠️ **デモ専用**：デモコインは購入・換金・譲渡ができず、金銭的な価値はありません。
> 実際のお金での賭け・入金・出金は実装していません（[法務・安全面の確認事項](docs/03-legal-and-safety.md)）。
> 登場する馬・人物・競馬場・レースはすべて架空です。

## 開発

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # Vitest
npm run build      # 型チェック + 本番ビルド（dist/）
```

## ロードマップ（ステップ実装）

| Step | 内容 | 状態 |
|---|---|---|
| 1 | 企画ドキュメント・プロジェクト雛形・CI | ✅ |
| 2 | レースシミュレーションエンジン（能力・展開・天候・馬場、シード検証） | ✅ |
| 3 | オッズ・券種の登録の仕組み・デモコイン台帳・責任ある利用・監査ログ | ✅ |
| 4 | 画面（トップ／遊び方／一覧／馬の詳細／確認／収支／設定）＋2D代替表示 | ⏳ |
| 5 | 3D観戦（コース・観客席・馬・カメラ・砂煙・画質設定） | ⏳ |
| 6 | 実況・振り返り解説・アクセシビリティ・GitHub Pagesでの公開 | ⏳ |

## ディレクトリ構成

```
src/
  core/     DOMに依存しないロジック（乱数・コース・シミュレーション・オッズ・台帳…）
  data/     架空の馬・騎手・レース名
  render/   3D（three.js）と2D代替表示
  ui/       画面
tests/      Vitest
docs/       企画・設計ドキュメント
```
